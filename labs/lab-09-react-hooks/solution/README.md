# Lab 9 reference solution

In the React project from Lab 8, install Axios with `npm install axios`.
Set `VITE_API_URL=https://jsonplaceholder.typicode.com` in `.env.local`.
Copy `api.js` to `src/api.js` and `solutions_example.jsx` to `src/App.jsx`.
The example limits the posts to ten to keep the list readable.
